# Plugins (Skills + Connectors Bundle)

> Skills + Connectors = Plugins.

## Description

A Plugin packages [[agentic-skills]] (domain best practices and expertise) together with [[ai-connectors]] (access to the relevant tools, e.g., a CRM or external service) into a single, complete domain solution installable in one click. Because Skills and Connectors already work together inside the bundle, a Plugin gives the agent a ready-made starting point for specialized work — for example, a commercial Plugin that already knows the team's CRM, process, and vocabulary.

## Key Characteristics

- Combines Skills (know-how) with Connectors (system access) as one unit
- Installed in a single action rather than configured piece by piece
- Provides a specialized starting point for one domain (e.g., commercial, compliance)

## Where it Applies

- Presented as the packaging layer above Skills and Connectors in Indicium's Claude Cowork enablement workshops (e.g., Portobank, Aug 2026).

## Related Concepts

- [[agentic-skills]] — one of the two components bundled into a Plugin
- [[ai-connectors]] — the other component bundled into a Plugin
