# Claude Cowork (2026 Interaction Model)

> All other functions gain the same execution power as developers had with Code — no terminal required.

## Description

Claude Cowork operates with far more autonomy than a single conversation. The user defines a goal and Claude handles the rest — planning, executing across tools and files, and reporting back — while questioning assumptions rather than simply agreeing. Unlike Chat, Cowork executes multi-step flows, creates real files (.docx, .xlsx, .pptx), connects to live data sources, and reuses Skills and Plugins.

## Key Characteristics

- Multi-step, autonomous execution instead of single-turn Q&A
- Produces real deliverables (documents, spreadsheets, presentations) directly
- Connects to live data (Drive, email, CRM, etc.) instead of requiring manual copy-paste
- Reuses Skills and Plugins across the user, the team, and the organization

## Where it Applies

- Core interaction model taught in Indicium's Claude Cowork enablement workshops (e.g., Portobank, Aug 2026), positioned as the tool of choice for "if it's work, start in Cowork."
