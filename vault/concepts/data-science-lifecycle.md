# Data Science Lifecycle

> Every era of data tooling removes one bottleneck in this chain — and creates a new scarcity at the next link.

## Description

A six-stage sequence: **Reality → Data Capture → Context/Modeling → Analysis → Consensus → Decision/Action**. The framework uses it as a diagnostic: each technological era in data infrastructure history solved the bottleneck at one link in this chain, which immediately exposed scarcity at the next one.

- **Cloud data warehouse era** ([[cloud-data-warehouse]]): solved data accessibility → created scarce analytical capacity.
- **Modern data stack era** ([[modern-data-stack]]): solved analytical capacity → created scarce operator capability.
- **Post-AI era** ([[post-ai-data-stack]]): solved dashboard/query creation → created scarce consensus.

The measure of a great data scientist shifts accordingly: not excellence at individual analyses, but the ability to scale judgment by encoding expertise into infrastructure, so future agents, decisions, and hires start from that accumulated representation of organizational truth.

## Key Characteristics

- Six stages: Reality → Data Capture → Context/Modeling → Analysis → Consensus → Decision/Action.
- Used retrospectively to explain why each infrastructure era solved one bottleneck and revealed the next.
- Frames "great data scientist" as a judgment-scaling role, not an individual-analysis role.
