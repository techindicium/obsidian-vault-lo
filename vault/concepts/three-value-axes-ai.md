# Three Value Axes of AI (People, Processes, Products)

> The return is compound: each layer multiplies the value of the one before it.

## Description

This framework — sometimes referred to informally as "People, Process, Product" — describes three axes through which AI generates measurable business value, each building on the previous: [[smarter-employees]] (AI in every function's daily work), [[faster-processes]] (operations redesigned with AI in the loop), and [[transformative-products]] (AI embedded in the product's own behavior and evolution). All three are sustained by a secure, governed AI platform underneath.

> **Provenance note:** this is Indicium's own consulting framework (co-branded with Anthropic in workshop materials), not a philosophy documented in Anthropic's official product documentation — see [[ai-transformation-office]] for the operating structure built around it.

## Key Characteristics

- Three axes: People (employees), Processes (operations), Products (customer-facing offerings)
- Value compounds — each axis multiplies the return of the previous one, not just adds to it
- Underpinned by a single secure, governed AI platform across all three axes

## Where it Applies

- Central framework of the ROI/strategy section in Indicium's Claude Cowork enablement workshops (e.g., Portobank, Aug 2026): 20–45% productivity gain (People), 30–60% unit-cost reduction (Processes), 200% more end-customer reach (Products).
