# Post-AI Data Stack

> The infrastructure paradigm for a world where AI makes analysis cheap but organizational consensus expensive.

## Description

Each era of data infrastructure removed one bottleneck and created a new scarcity. The Post-AI Data Stack (2026) is the response to the current one: as coding agents and AI-native tools let anyone generate analysis independently, **consensus** — not access, not compute — becomes the limiting resource. Data teams must balance two goals simultaneously: letting every employee analyze data and deploy AI independently, while maintaining a single, agreed-upon source of truth.

The stack embeds expert judgment directly into infrastructure so that agents can produce reliable analysis without a data scientist reviewing every output.

## Key Characteristics

- Optimizes for **algorithmic consumption first** — data products are built to be read and recombined by agents, not just humans clicking through dashboards.
- Treats **consensus as an engineerable, measurable property**, not an emergent side effect of org structure.
- Rejects vendor lock-in — context must stay portable across interfaces and models.
- Compounds institutional judgment into infrastructure so each future question starts smarter than the last.

## Components

The framework names four infrastructure requirements and two operating disciplines:

- [[agent-readable-artifacts]] — data outputs designed for agents to decompose and reassemble, not just humans to view.
- [[agent-operable-tools]] — tools that expose APIs/MCP as primary interfaces so agents can act on them programmatically.
- [[agent-agnostic-context]] — headless, portable semantic context that doesn't lock an org into one vendor.
- [[agent-testable-consensus]] — treating agreement on metrics as something you can query, measure, and drive toward zero divergence.
- [[compounding-improvements]] — hardening context via evaluation traces rather than waiting on frontier models to compensate.
- [[beyond-sql]] — handling narrative, not just numerical, questions through the same infrastructure.
