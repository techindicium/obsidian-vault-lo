# AI Security Controls Inventory

> AISVS's Appendix B: a cross-reference table mapping the standard's controls to the categories and threats each one addresses — an audit/lookup aid, not a new set of requirements.

## Description

Rather than introducing additional verification requirements, this appendix helps auditors and implementers navigate [[aisvs-core-categories|the 12 core control categories]] by threat or control name — useful when starting from "what mitigates jailbreak?" or "what covers supply chain risk?" rather than from a specific chapter number.

## Where it Applies

- [[aisvs-standard]] — this is one of its three appendices
- [[aisvs-core-categories]] — this inventory cross-references every category
