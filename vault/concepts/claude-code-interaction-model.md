# Claude Code (2025 Interaction Model)

> Developers got access to another category — AI that goes beyond answering questions.

## Description

The second stage in the Chat → Code → Cowork evolution. Developers were the first group to get an AI interaction model with real execution power over their domain (code, terminal, files), rather than only conversational Q&A.

## Key Characteristics

- Execution capability scoped initially to developers and code-related tools
- Precursor to the general-purpose agentic execution later extended to all functions in Cowork
- Marks the shift from "AI that answers" to "AI that acts"

## Where it Applies

- Referenced as the historical precedent that legitimizes extending agentic execution to non-developer roles via Cowork, in Indicium's Claude enablement workshops.
