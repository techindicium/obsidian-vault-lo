# Label + Calibrated Question (Rapport Tactic)

> A negotiation-derived rapport technique (from Chris Voss's *Never Split the Difference*): name an observed, verifiable fact about the other person (the "label"), then follow it with an open-ended, calibrated question — instead of relying on mirrored language or presumed shared interests.

## When to use it

Useful when there isn't enough reliable personal information (hobbies, quotes, public talks) to build rapport through mirrored language or shared-interest openers — using unconfirmed personal details risks sounding wrong and breaking trust on first contact.

## How it works

1. Identify one real, verifiable fact about the person (a career move, a known transition, a documented background detail).
2. State it as an observation ("label"), not a compliment or assumption.
3. Follow immediately with an open, calibrated question ("how...", "what...") that invites the person to describe themselves, rather than having their profile guessed at.

## Applied example

- [[paulo-pituba]] — used as the recommended opening approach given the near-total absence of public material on him. The label used was his real career transition (Rede → C6 Bank); the calibrated question asked how that transition shapes his view on AI applied to banking operations.

## Part of a broader toolkit

This is one specific technique within the larger [[never-split-the-difference-negotiation-tactics]] playbook — the variant best suited when there is very little public information available to build rapport on.
