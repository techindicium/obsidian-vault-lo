# The Compound Effect (AI Adoption)

> Your systems come to you. Your context finds you. Your workflows run alongside you.

## Description

A framing for why the value of [[ai-connectors|Connectors]], context, and [[ai-automation-routines|automation]] compounds rather than simply adds up: once systems are connected, context stops needing to be manually gathered, and once workflows are automated, they keep running alongside the user without repeated setup. Each capability reduces the friction of the next.

> **Note:** flagged as semantically related (0.85 similarity) to [[three-value-axes-ai]] during extraction — both describe compounding value, but this concept is specifically about the Connectors/Context/Automation stack, while Three Value Axes is the broader People/Process/Product business framework.

## Key Characteristics

- Systems come to the user (via Connectors) instead of the user going to the systems
- Context finds the user instead of being manually re-gathered each time
- Workflows run alongside the user (via Automation) instead of requiring repeated manual triggers

## Where it Applies

- Presented as a transition summary between Connectors/Plugins and Automation in Indicium's Claude Cowork enablement workshops (e.g., Portobank, Aug 2026).
