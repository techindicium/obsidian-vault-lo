# ISO/IEC 27001

> The certifiable international standard for an Information Security Management System (ISMS) — the security-management analogue [[iso-42001|ISO/IEC 42001]] was structurally modeled on.

## Description

Captured here as a lightweight reference stub because [[iso-42001|ISO/IEC 42001]] shares its Harmonized Structure (the same clause 4-10 numbering) with ISO 27001, and organizations already certified against ISO 27001 typically cut their ISO 42001 certification effort by roughly a third to a half. This entry should be expanded if a future source in this vault ingests ISO 27001 directly.

## Where it Applies

- [[iso-42001]] — shares its Harmonized Structure and reduces certification effort for existing holders
