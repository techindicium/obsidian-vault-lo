# Agentic Dev

> Developers and the SDLC gain traction and accelerate time-to-market.

## Description

Agentic Dev is the pillar of an [[ai-transformation-office]] focused on software engineering: adopting Claude Code and agentic development practices to speed up the software development lifecycle (SDLC) and reduce time-to-market for new capabilities.

## Key Characteristics

- Targets the software development lifecycle specifically, not general office work
- Builds directly on the [[claude-code-interaction-model]] execution capability
- Maps to the "Faster Processes" value axis in terms of operational speed-up

## Where it Applies

- Positioned as the second of three AITO pillars (with Workplace Transformation and Core Innovation) in Indicium's Claude Cowork enablement workshops (e.g., Portobank, Aug 2026).
