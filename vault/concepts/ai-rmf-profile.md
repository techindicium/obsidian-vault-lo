# AI RMF Profile

> A tailored application of the AI RMF's functions, categories, and subcategories to a specific setting — a use case, sector, technology, or organizational context — based on the requirements, risk tolerance, and resources of that setting.

## Description

Profiles let organizations translate the generic [[ai-rmf-core-functions|AI RMF Core]] into concrete, contextualized guidance rather than applying the framework abstractly. NIST has published companion profiles as the framework matures (e.g., a Generative AI Profile and a Critical Infrastructure Profile concept note) — these are separate NIST publications, not part of the base AI RMF 1.0 text, and should be captured as their own entities if and when ingested directly.

## Key Characteristics

- Scoped to a use case, sector, technology, or organization rather than being generic.
- Built from the same functions/categories/subcategories as the AI RMF Core — a profile doesn't redefine the framework, it applies it.
- The mechanism by which the AI RMF stays relevant as new AI technologies (e.g., generative AI) and new regulated sectors emerge.

## Where it Applies
