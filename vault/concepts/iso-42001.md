# ISO/IEC 42001:2023 AI Management System

> The international standard specifying requirements for establishing, implementing, maintaining, and continually improving an organizational AI Management System (AIMS).

## Description

Captured here as a lightweight reference stub because [[aisvs-standard|AISVS]] cites ISO/IEC 42001 as a complementary governance framework: where AISVS provides testable, engineering-level security requirements, ISO 42001 provides the organizational management-system layer (policies, roles, continual improvement processes) that governs how AI is developed and operated more broadly — similar in scope role to how the [[nist-ai-risk-management-framework|NIST AI RMF]] is also cited.
