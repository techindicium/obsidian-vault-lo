# Nonviolent Communication (CNV)

> A four-pillar structure — Observation, Feeling/Impact, Need, Request — for raising a disagreement or a difficult message without triggering defensiveness.

## Description

CNV (Comunicação Não-Violenta) structures a difficult message into four ordered pillars, applied in sequence:

| Pillar | What it does |
|---|---|
| Observation | State the facts, without judgment or interpretation |
| Feeling / Impact | Name the real impact of what happened |
| Need | State what needs to happen, and why |
| Request | Make a clear, possible, positive ask — with a deadline |

The framework is deliberately fact-first and judgment-last: it separates "what happened" from "what it means" before asking for anything, which lowers the odds the other side reacts defensively. It closes with support and a follow-up commitment rather than leaving the ask hanging.

## Key Characteristics

- Four ordered pillars: Observation → Feeling/Impact → Need → Request
- Facts before interpretation — avoids judgment language in the opening move
- The request is always concrete, achievable, and time-boxed
- Pairs naturally with a closing follow-up commitment ("we'll track this in the next meeting")
