# OWASP Application Security Verification Standard (ASVS)

> OWASP's original catalogue of testable, verifiable application security requirements, organized by verification level (L1/L2/L3) — the standard [[aisvs-standard|AISVS]] is directly modeled on.

## Description

Captured here as a lightweight reference stub because [[aisvs-standard|AISVS]] cites it as the standard it follows both in philosophy (every requirement verifiable and testable) and structure (leveled L1/L2/L3 requirements). AISVS deliberately keeps a narrow AI-specific scope precisely because general application security is ASVS's domain — the two are meant to be applied together, not as substitutes for each other. This entry should be expanded if a future source in this vault ingests ASVS directly.

## Where it Applies

- [[aisvs-standard]] — the parent standard AISVS is modeled on and meant to be applied alongside
